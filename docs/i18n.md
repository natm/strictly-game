# Languages

The game screens can be shown in other languages, picked from the flag menu in the header and saved per browser (`S.lang`).
Only the game's own UI is translated. Couples' names, facts and presenter and judge comments stay in English.

## How it works
- `tr(text, vars)` in `index.html` looks up the English text in `window.I18N_<CODE>`, falling back to English, and fills `{placeholders}`. For example: `tr('Start Week {n}', {n: 7})`.
- `plural(n, one, many)` picks the right English key. Welsh keeps the noun singular after numbers, so both keys can map to the same translation.
- Translations can contain simple HTML (`<b>…</b>`) where the English does.

## Adding a language
1. Copy `i18n/cy.js` to `i18n/<code>.js`, rename `window.I18N_CY` to `window.I18N_<CODE>`, and translate the right-hand side only.
2. Add `<script src="i18n/<code>.js"></script>` next to the Welsh one in `index.html`.
3. Add `{code, flag, name}` to `LANGS` in `index.html`.

## Adding UI text
Wrap any new on-screen text in `tr('…')` (with `{placeholders}` for names and numbers) and add the same key to every `i18n/*.js` file. Missing keys just show in English.
